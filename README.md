# GamesTable

Личный трекер компьютерных игр: во что играете сейчас, что хотите пройти, что уже прошли —
и что хотите просто посмотреть прохождением или игрофильмом на YouTube и Twitch.

PWA: работает на Android, iPhone и в вебе из одной кодовой базы, ставится на домашний
экран. Библиотека хранится на устройстве, аккаунт не нужен.

**→ [games-table-bay.vercel.app](https://games-table-bay.vercel.app)**

Свободный фан-проект. Не аффилирован с RAWG, Valve, YouTube или Twitch.

## Возможности

- **Две дорожки статусов:** играть (хочу сыграть → играю → сыграл) и смотреть
  (хочу посмотреть → смотрю → посмотрел), плюс «бросил».
- **Библиотека** с вкладками PLAYING / BACKLOG / PLAYED / WATCH; вкладка просмотра
  разбита на секции «смотрю», «хочу посмотреть» и «посмотрел» и фильтруется по каждому
  из них.
- **Страница игры:** обложка, год, платформы, жанры, оценка Metacritic, ваша оценка 1–10,
  часы, заметка и платформа, на которой играли или смотрели.
- **Рекомендации «For you»** — считаются на устройстве по вашей же библиотеке, и каждая
  карточка объясняет, почему она здесь.
- **Ссылки на просмотр:** YouTube (longplay, game movie, walkthrough, review) и Twitch —
  одним тапом, без встроенных плееров и без чужого трекинга.
- **Профиль:** статистика по статусам, платформам и жанрам, экспорт и импорт бэкапа,
  форма фидбэка и контакты, поддержка проекта.
- **Скрытая страница `/#/insights`** — счётчики использования этого устройства и
  диагностика: видно, какой источник отвечает и не работает ли приложение на одном Steam.
- **Тема:** системная, светлая или тёмная, закрепляется независимо от устройства.

## Данные

| Источник | Что даёт | Ключ |
|---|---|---|
| [RAWG](https://rawg.io/apidocs) | все платформы, обложки, рейтинги | бесплатный, нужен |
| Steam | PC-игры без ключа — запасной путь | не нужен |

Оба идут через тонкий serverless-прокси: ключ RAWG нельзя держать в браузере, а Steam
вообще не отдаёт CORS-заголовки. Подробности и замеры —
[docs/DATA-SOURCES.md](docs/DATA-SOURCES.md).

## Запуск

```bash
npm install
npm run dev
```

Поиск заработает только с запущенным прокси — это следствие того, что оба источника
недоступны из браузера напрямую:

```bash
echo 'RAWG_API_KEY=<ключ>' > .env.local        # файл в .gitignore
node --env-file=.env.local scripts/dev-api.mjs # прокси на :3001
npm run dev                                    # Vite сам проксирует /api на него
```
